# 云锦工坊 · 接单打样交付台

直接用浏览器打开 `index.html` 即可使用，无需服务器、无需联网。数据保存在浏览器 localStorage，刷新不丢失；支持一键导出 JSON 备份，换机器后导入即可完整还原。

## 流程

客户订单（客户、纹样、规格、数量、交期）→ 自动建立打样单 → 保存多个打样版本，记录送样 / 反馈 / 客户通过 / 退样（退样后可新建版本重打，通过后版本锁定）→ 用确认样生成生产批次 → 选机台和起止日期排产 → 按色线领料出库 → 开工织造、登记耗用 → 完工（未耗色线自动退库）→ 质检（不合格返工）→ 登记批次交付。

## 拦截规则

- 确认样通过前不能生成批次、不能排产；
- 排产检查机台档期重叠、日期顺序，领料后档期锁定不能重复排产；
- 累计排产、累计交付都不能超过订单数量；交付不能超过本批数量；
- 领料按确认样单件用量 × 批量核算，库存不足直接拦截，支持分次领料；
- 耗用不能超过已领未退数量；只有织造中批次能完工，防止重复完工；
- 取消生产必须填原因，释放机台档期，已领未耗色线全部退回并留下库存流水。

## 页面

- **总览**：待办、冲突（缺线 / 机台冲突 / 后续排产缺线预警）、各色线余量，点击直达处理；
- **客户订单 / 打样确认 / 生产批次 / 色线库存 / 批次交付** 五个工作台；
- **色线库存** 含期初、采购入库、领料出库、耗用登记、余线退库、取消退回、盘点调整的完整流水账，每笔带结存余量。

首次打开自动载入一套演示数据（含待办、缺线冲突、返工批次、逾期订单等各状态样例）；页头「重置为演示数据」可随时还原。
